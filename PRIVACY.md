# Privacy Policy for Paragraph Processor Chrome Extension

**Last updated**: December 2024

## Overview

The Paragraph Processor Chrome Extension ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, and protect your information when you use our Chrome extension.

## Information We Collect

### Text Content
- **What**: Text content from web pages you visit when you use the "Pin to process text" feature
- **When**: Only when you explicitly pin text for processing
- **Purpose**: To provide Natural Language Processing (NLP) analysis and highlight noun phrases

### User Preferences
- **What**: Your extension settings (e.g., whether NLP processing is enabled)
- **Storage**: Locally in your browser using Chrome's sync storage
- **Purpose**: To remember your preferences across browser sessions

### Technical Information
- **What**: Browser version, extension version, and error logs
- **Purpose**: To improve extension functionality and debug issues

## How We Use Your Information

### NLP Processing
When you enable NLP processing and pin text:
1. The selected text is sent to our NLP API server
2. The API analyzes the text to identify noun phrases
3. Results are returned to highlight noun phrases on the webpage
4. Text content is not stored permanently on our servers

### Data Processing
- **Local Processing**: Word counting and basic text analysis happen locally in your browser
- **Remote Processing**: NLP analysis is performed on our secure API server
- **Caching**: API responses are cached locally to improve performance

## Data Sharing and Third Parties

### Our NLP API
- **Service**: We operate our own NLP API server
- **Data**: Only text content you explicitly choose to process
- **Security**: All communication is encrypted via HTTPS
- **Retention**: Text content is not permanently stored

### No Third-Party Sharing
We do not sell, trade, or otherwise transfer your information to third parties for commercial purposes.

## Data Security

### Encryption
- All API communications use HTTPS encryption
- Local storage uses Chrome's secure storage mechanisms

### Access Controls
- Only text you explicitly choose to process is sent to our servers
- No automatic data collection or tracking

### Data Retention
- **Local Cache**: API responses cached for 5 minutes locally
- **Server Storage**: Text content is not permanently stored on our servers
- **User Preferences**: Stored locally until you clear browser data

## Your Rights and Choices

### Control Your Data
- **Disable NLP**: You can disable NLP processing in the extension settings
- **Clear Cache**: Extension cache is automatically cleared every 5 minutes
- **Uninstall**: Removing the extension deletes all local data

### Access and Deletion
- **Local Data**: You can clear extension data through Chrome's extension management
- **API Data**: No persistent data is stored on our servers

## Children's Privacy

Our extension is not intended for children under 13. We do not knowingly collect personal information from children under 13.
